## Задания

### Задание 1 — Анализ функции foo(s) (вариант 3)

**Файл:** `ex1.py`

**Что выполняет функция:**  
Функция `foo(s)` принимает строку `s`, перебирает все её символы и суммирует числовые значения цифр, встречающихся в строке. Если символ не является цифрой — он пропускается. Возвращает сумму всех цифр строки.

**Вычислительная сложность:** `O(N)`, где `N` — длина строки. Один проход по строке, каждая операция внутри цикла выполняется за константное время.

**График:** зависимость времени выполнения от длины строки `N` для значений 10 000, 50 000, 100 000, 500 000 и 1 000 000 символов.

---

### Задание 2 — Поиск трёх максимальных значений (вариант 3)

**Файл:** `ex2.py`

**Условие:**  
Дан список случайных чисел. Определить три самых больших значения списка.

**Алгоритм 1 — трёхкратный поиск максимума:**  
Три раза находится максимум в копии списка, после чего найденный элемент удаляется.  
**Сложность:** `O(N)` (три линейных прохода).

**Алгоритм 2 — полная сортировка:**  
Список сортируется, затем берутся три последних элемента.  
**Сложность:** `O(N log N)` (сортировка Timsort).

**График:** сравнение времени работы обоих алгоритмов на массивах размером от 100 до 50 000 элементов.

---

### Задание 3 — Аналитическое решение (вариант 3)

**Файл:** `ex3.py`

**Условие:**  
Даны зависимости количества операций от размера массива:

```
T1(N) = N² - N - 10
T2(N) = 4N + 40
```

Требуется найти размер массива `N`, при котором время выполнения обоих алгоритмов одинаково.

**Решение:**  
Приравниваем `T1(N) = T2(N)`:

```
N² - N - 10 = 4N + 40
N² - 5N - 50 = 0
```

Дискриминант: `D = 25 + 200 = 225`, `√D = 15`.

Корни: `N1 = 10`, `N2 = -5`.

Отрицательный корень отбрасывается как физически бессмысленный.

**Ответ:** `N = 10`.

**Примечание:** программа реализует аналитическое решение через дискриминант квадратного уравнения.

### Задание 4 — Сравнение оператора del для list и dict

**Файл:** `ex4.py`

**Цель:**  
Сравнить производительность удаления элемента по индексу/ключу из списка и словаря.

**Методика:**  
Для размеров `N` от 100 000 до 1 000 000 создаются список `list(range(N))` и словарь `{i: i}`. Удаляется элемент с индексом `N // 2`. Замеряется время операции `del`.

**Теоретические сложности:**

| Структура | Сложность `del` | Причина |
|-----------|-----------------|---------|
| `list`    | `O(N)`          | Сдвиг всех элементов после удаляемого |
| `dict`    | `O(1)`          | Прямой доступ по хешу ключа |

**График:** зависимость времени `del` от размера структуры. Время удаления из списка линейно растёт, время удаления из словаря остаётся практически нулевым.

### Задание 5 — Сравнение оператора in для list и set

**Файл:** `ex5.py`

**Цель:**  
Сравнить производительность проверки принадлежности элемента множеству и списку.

**Методика:**  
Для размеров `N` от 100 000 до 1 000 000 создаются список `list(range(N))` и множество `set(range(N))`. Проверяется наличие заведомо отсутствующего элемента (`target = -1`), чтобы каждый раз выполнялся полный проход для списка. Замеряется время операции `in`.

**Теоретические сложности:**

| Структура | Сложность `in` | Причина |
|-----------|----------------|---------|
| `list`    | `O(N)`         | Последовательный перебор всех элементов |
| `set`     | `O(1)`         | Проверка по хеш-таблице |

**График:** зависимость времени `in` от размера структуры. Для списка время линейно растёт, для множества — остаётся постоянным.

## Установка и запуск

### Требования

- Python 3.9 или выше
- Matplotlib

### Установка зависимостей

```bash
pip install matplotlib
```

### Запуск

Каждый файл запускается отдельно:

```bash
python ex1.py
python ex2.py
python ex3.py
python ex4.py
python ex5.py
```

Файлы `ex1.py`, `ex2.py`, `ex4.py`, `ex5.py` открывают окно с графиком.  
Файл `ex3.py` выводит результат в консоль.

## Примечания

- Замеры времени выполняются с помощью `time.perf_counter()` — наиболее точного таймера в Python.
- Для чистоты эксперимента структуры данных создаются заново на каждой итерации.
- В заданиях 1, 2, 4, 5 размеры входных данных подобраны так, чтобы разница в производительности была наглядно видна на графике.
